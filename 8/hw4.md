# Домашнее задание 4. Video RAG по своему архиву

Соберите систему, которая принимает вопрос, ищет фрагменты в нескольких видео и возвращает ответ с проверяемым источником.

1.  Подготовьте архив и проверочные вопросы

- Возьмите 5–10 роликов на одну тему, например готовка, настольные эксперименты, спорт или работа с инструментами.
- Составьте 5–10 вопросов с эталонным ответом и одним или несколькими допустимыми интервалами. 
- Добавьте 2–3 правдоподобных вопроса, ответа на которые в архиве нет. 


2. Соберите поиск и генерацию

- Разбейте видео на окна. Храните ID окна, ID видео, границы в секундах и эмбеддинг.
- Для базового поиска получите нормализованные CLIP-эмбеддинги кадров, усредните их внутри окна и нормализуйте средний вектор. Можете использовать другие энкодеры.
- Передайте три найденных окна в Qwen-VL как клипы или коллажи с ID. Попросите ответ и ID фрагмента. По ID подставьте имя видео и таймкод.


3. Оцените систему
   
- Вручную проверьте смысловую правильность ответа и подтверждает ли его процитированный фрагмент. Приведите оба показателя и долю случаев, в которых выполнены оба условия.
- Hit@3 для поиска. На вопросах с ответом посчитайте долю случаев, где хотя бы одно из трёх найденных окон из нужного видео покрывает ≥80% хотя бы одного эталонного интервала. Покрытие — длительность пересечения, делённая на длительность эталонного интервала. Укажите также, для скольких вопросов в индексе вообще есть подходящее окно.
