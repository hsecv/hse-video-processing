# Домашнее задание 2. Трекинг в новом домене

В практике мы сравнивали трекеры на MOT17 — городских сценах с пешеходами. В этом задании нужно перенести тот же пайплайн в другой домен, проверить несколько детекторов и понять, что сильнее ограничивает качество: детекция или ассоциация объектов между кадрами.

## Цель

Собрать воспроизводимый эксперимент и сравнить свой SORT со вторым раундом матчинга с готовым трекером из `ultralytics`.

1. Выберите данные

Выберите **один** из вариантов(или возьмите свой) и возьмите **одну–две последовательности** из train/val-части, для которых доступна разметка.

Вариант 1 — спорт

- [SportsMOT: статья](https://arxiv.org/abs/2304.05170)
- [Официальный репозиторий и ссылки на данные](https://github.com/MCG-NJU/SportsMOT)
- целевой класс — игроки на площадке;

Вариант B — дрон

- [VisDrone2019-MOT: официальный репозиторий](https://github.com/VisDrone/VisDrone-Dataset)
- выберите **один** целевой класс: `pedestrian` или `car`;

2. Получите детекции

Запустите YOLO из `ultralytics` в **нескольких конфигурациях**. Это могут быть:

- две модели разного размера, например `n` и `m`;
- одна модель при двух значениях `imgsz`;
- готовая модель и ваша дообученная версия.

3. Запустите трекеры

Для каждой конфигурации детектора сравните:

- ваш SORT из практики со вторым раундом матчинга;
- ByteTrack или BoT-SORT из `ultralytics`

4. Посчитайте метрики

Оцените результаты через:

- `HOTA`, `DetA`, `AssA`, `LocA`;
- `MOTA`, `IDF1`, `IDSW`;
- `FP`, `FN`;
