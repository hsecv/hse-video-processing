# Домашнее задание 1. Video representations

Цель работы — проверить, насколько качество video classification определяется внешним видом отдельных кадров и насколько модель действительно использует временную информацию и движение.


**1. Выберите один датасет, отличный от UCF101, например:**

- HMDB51 — 15 классов;

- Something-Something v2 — 15–25 классов;

- Jester — 15 классов.

Зафиксируйте train/validation/test split и random seed. Кратко опишите датасет и используемый subset.

**2. Дообучите две модели:**

- X3D-S или R(2+1)D-18;

- VideoMAE-B.

Используйте одинаковый протокол обучения и фиксированное число кадров на видео.

Для каждой модели измерьте метрики качества.

**3. Сравните полноценную video-модель с тремя вариантами без нормальной временной информации:**

- ResNet-50 по центральному кадру;

- ResNet-50 с усреднением predictions/features по 8 кадрам;

- video-модель, которой один кадр повторяется T раз вместо настоящего видео.

Для video-моделей вычислите

r = accuracy(single-frame) / accuracy(video)

как для всего датасета, так и для отдельных классов.

Чем ближе r к 1, тем больше модель может решать задачу по appearance, не используя движение.

**4. Постройте:**

- график accuracy single frame vs video для каждого класса;

- confusion matrix для single-frame модели;

- примеры классов, где движение особенно важно и где оно почти не требуется.

Объясните, какие визуальные признаки позволяют определить класс без просмотра движения.
