# Домашнее задание 6. SAM 2 на собственном видеодатасете

В этом задании нужно собрать небольшой тематический датасет, сравнить способы задания объекта для SAM 2 и проверить ещё один метод видео-сегментации в едином протоколе.

Цель - Понять, как тип начальной подсказки и дополнительные исправления влияют на распространение маски по видео, и отделить красивый визуальный результат от измеримого качества.

1. Соберите датасет

Подберите **15–20 клипов** одной тематики:

- домашние животные;
- люди на спортивной площадке;
- машины на парковке;
- другая согласованная тема.


2. Сравните способы задания объекта в SAM 2

Используйте официальный [SAM 2](https://github.com/facebookresearch/sam2) и одну фиксированную конфигурацию модели для основного сравнения. На пяти размеченных клипах запустите четыре режима:

1. **одна positive point** внутри объекта на первом кадре;
2. **positive + negative points** на первом кадре;
3. **bounding box** целевого объекта на первом кадре;
4. **полная GT-маска первого кадра** как mask prompt.

3. Сравните с другим методом

Выберите **один** дополнительный метод видео-сегментации или распространения маски. Примеры:

- [XMem](https://github.com/hkchengrex/XMem);
- [Cutie](https://github.com/hkchengrex/Cutie);
- другой открытый VOS-метод;
- базовый метод на optical flow с переносом маски между кадрами.


4. Оцените качество

На размеченных кадрах посчитайте:

- `J` — IoU масок;
- `F` — boundary F-measure;
- `J&F = (J + F) / 2`;
